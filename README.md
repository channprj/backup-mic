# DJI Mic Backup

DJI Mic Mini 2S 케이스를 USB-C로 연결하면 두 송신기의 WAV 녹음을 로컬 폴더에 자동 백업하는 macOS 메뉴 막대 앱입니다. 복사된 파일은 크기와 SHA-256을 다시 검사하며, 검증이 끝나기 전에는 원본 삭제 기능을 제공하지 않습니다.

## 주요 동작

- TX01과 TX02를 볼륨 이름이나 마운트 경로가 아닌 물리 장치 특성으로 식별합니다.
- 연결된 녹음이 2초 동안 변하지 않은 일반 WAV 파일인지 확인한 뒤 백업합니다.
- 첫 실행에서 기본 백업 위치 `/Users/channprj/Documents/DJI-Mic-Mini-2S`를 확인하거나 다른 로컬 폴더를 선택합니다.
- 녹음은 날짜와 송신기별 하위 폴더에 정리됩니다.
- 같은 녹음을 다시 연결하면 기존 파일을 재검증하며 중복 복사본을 만들지 않습니다.
- 메뉴 막대 팝오버에서 전체 진행률, TX01/TX02 진행률, 검증 결과와 최근 활동을 확인할 수 있습니다.
- 네트워크 통신, 클라우드 업로드, 분석 도구, 전사 기능은 없습니다.

## 설치

요구 사항은 macOS 13 이상과 Apple Silicon Mac입니다. 로컬 패키지는 Developer ID 서명이나 공증을 하지 않는 개인용 빌드입니다.

```bash
pnpm install --frozen-lockfile
./scripts/package-local.sh
```

완성된 `.app`과 `.dmg` 경로는 스크립트 마지막에 출력됩니다. DMG를 열어 앱을 `Applications` 또는 `~/Applications`에 복사합니다. macOS가 로컬 빌드 실행을 막으면 Finder에서 앱을 Control-클릭한 뒤 `열기`를 선택합니다.

## 처음 사용

1. 앱을 처음 열면 나타나는 macOS 폴더 선택 창에서 기본 백업 폴더를 확인합니다. 이 선택으로 앱에 해당 폴더 접근 권한이 부여됩니다.
2. DJI Mic 케이스에 두 송신기를 넣고 USB-C로 Mac에 연결합니다.
3. 메뉴 막대의 DJI Mic Backup 아이콘을 누릅니다.
4. 표시된 두 저장 장치를 TX01과 TX02에 지정하고 `이 송신기로 연결`을 누릅니다.
5. 즉시 첫 백업이 시작됩니다. 완료될 때까지 케이스를 분리하지 않습니다.
6. `백업 검증 완료`와 녹음 수·용량·완료 시간이 표시되면 백업이 끝난 것입니다.

페어링 정보와 작업 이력은 이 Mac의 앱 데이터 폴더에만 저장됩니다. 메뉴 막대 팝오버의 `로그인할 때 시작`을 켜면 이후 로그인부터 백그라운드에서 자동 실행됩니다.

## 원본 삭제

삭제는 자동으로 실행되지 않습니다. 백업이 완전히 검증된 송신기에만 `TX01 원본` 또는 `TX02 원본` 버튼이 나타납니다.

1. 삭제할 송신기의 원본 버튼을 누릅니다.
2. 파일 수와 용량을 확인합니다.
3. `검증 후 원본 삭제`를 누릅니다.
4. 앱이 장치 정체성, 현재 파일 전체, 백업 파일 전체를 다시 확인한 뒤 일치할 때만 삭제합니다.

삭제 제안은 5분 후 만료됩니다. 장치 분리, 목적지 변경, 새 스캔, 백업 시작 또는 파일 변화가 감지되면 즉시 무효화됩니다. 삭제는 되돌릴 수 없으므로 필요한 녹음이 백업 폴더에 있는지 먼저 확인하세요.

## 장애와 복구

- 백업 중 장치가 분리되거나 파일이 바뀌면 원본은 유지되고 다음 연결에서 다시 시도합니다.
- 숨김 부분 파일은 앱이 소유한 이름만 정리합니다. 이미 존재하는 대상 파일은 덮어쓰지 않습니다.
- 앱이 강제 종료되면 진행 중 작업은 중단으로 기록되고 다음 실행에서 안전하게 재검증합니다.
- 백업 기록 데이터베이스가 손상되면 격리한 뒤 새 기록을 만들며, 안전을 위해 원본 삭제는 다시 백업할 때까지 잠깁니다.
- `저장 공간이 부족합니다`가 표시되면 백업 후에도 10 GiB가 남도록 목적지 공간을 확보합니다.
- 상태가 갱신되지 않으면 메뉴 막대를 다시 열고 `지금 백업`을 누릅니다. 계속 실패하면 앱을 종료한 뒤 다시 실행합니다.

앱은 원본 파일명, 전체 경로, 볼륨 UUID, 해시를 WebView나 알림에 노출하지 않습니다. 로컬 진단이 필요하면 사용자 경로를 출력하지 않는 다음 명령을 사용합니다.

```bash
./scripts/hardware-inventory.sh
```

## 독립 백업 확인

이 스크립트는 원본과 대상의 SHA-256을 별도로 계산해, 모든 원본 WAV 해시가 대상에 존재하는지 확인합니다. 파일명이나 경로는 출력하지 않습니다.

```bash
./scripts/verify-backup.sh \
  /Users/channprj/Documents/DJI-Mic-Mini-2S \
  /Volumes/DJI-MIC-1 \
  /Volumes/DJI-MIC-2
```

운영 중 볼륨 이름이 바뀌었다면 Finder에 표시된 현재 마운트 경로를 전달합니다. 이 스크립트는 원본과 대상을 읽기만 합니다.

## 개발과 검증

```bash
pnpm install --frozen-lockfile
./scripts/check.sh
./scripts/accept-deletion-fixture.sh
pnpm tauri dev
```

삭제 수용 테스트는 임시 FAT32 디스크 이미지만 생성·마운트해 검증한 뒤 분리합니다. 연결된 DJI Mic 볼륨은 테스트 대상으로 허용하지 않습니다.

브라우저에서 네이티브 IPC 없이 UI 상태만 확인하려면 `pnpm dev` 실행 후 다음 주소를 엽니다.

- `http://127.0.0.1:1420/preview.html?state=copying`
- `http://127.0.0.1:1420/preview.html?state=complete`
- `http://127.0.0.1:1420/preview.html?state=error`
- `http://127.0.0.1:1420/preview.html?state=pairing`

안전 핵심은 `src-tauri/crates/backup-core`의 Tauri 비의존 Rust 코드에 있습니다. React는 엄격한 Zod DTO를 통해 아홉 개의 좁은 명령만 호출하며 파일 시스템, 셸, 네트워크 또는 임의 경로 열기 권한을 갖지 않습니다.
